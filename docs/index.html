Processador de Faturas de Energia

Versão web — roda inteiramente no seu navegador.

Seus PDFs não são enviados a lugar nenhum: o processamento acontece na sua máquina, dentro da aba, via WebAssembly.

O que esta versão não faz (use o aplicativo desktop para isso):
  • Faturas CHESP escaneadas — precisam de OCR (Tesseract), que não roda no navegador. São detectadas e listadas, não processadas.
  • Borderôs — a leitura por coordenadas usa PyMuPDF, que não tem versão WebAssembly.
